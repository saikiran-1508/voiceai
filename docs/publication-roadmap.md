# Incremental publication roadmap

The initial upload contains seven setup and documentation commits made on their
actual publication date. These are publication milestones for an existing local
prototype, not a claim that it was developed over seven separate days.

The source publication adds seven more commits, grouped as follows:

1. Speech dependency and microphone diagnostics.
2. Exact command matching and Windows application launch functions.
3. LangGraph state, conditional routing and result reporting.
4. Microphone capture, offline transcription and the Tkinter interface.
5. Launch scripts and workflow demo.
6. Automated command and workflow tests.
7. Updated documentation for the complete source publication.

Further development may add flexible language-model interpretation, Firebase and
mobile access. These features are planned rather than implemented.

The current source publication is complete. Future changes can be published as
features are implemented and checked. No background publishing schedule is configured.
